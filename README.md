# Shoes Store - Quiz Praktikum Web

Website *landing page* produk sepatu sederhana berbasis menggunakan HTML, CSS, dan JavaScript.

## ✨ Fitur Utama
* **Product Card**: Menampilkan informasi sepatu *Air Runner*, harga, dan tombol *Add to Cart*.
* **Ganti Warna Card (JS)**: Mengubah warna latar kartu (*Black*, *Blue*, *Cream*) secara dinamis menggunakan (`getElementById` & `onclick`).

## 🛠️ Teknologi
* **HTML & CSS**: Struktur dan layout.
* **JavaScript**: logika.

## 🚀 Cara Menjalankan
1. Clone repositori ini:
   ```bash
   git clone https://github.com/rezasyahputra07/Tugas-Latihan-Quiz-Praktikum-Web_Shoes-Store.git
   ```
2. Buka berkas `index.html` langsung di (*browser*).
